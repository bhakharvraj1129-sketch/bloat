# Tester roster (template)

For the owner. One row per tester, 3 to 5 in this round. **Keep the filled-in roster private** (for example in your password manager or a private note), never in the repository or a shared document. **Never write a password in it.** The same columns are in `tester-roster-template.csv` for a spreadsheet.

|---|---|---|---|---|
| *Example (made up): A. Example* | *a.example@example.com* | *iPhone 13, Safari* | *the messaging app you already use with them* | *text message to their phone* |
| | | | | |
| | | | | |
| | | | | |
| | | | | |

- **Email:** the address their account is made with (it goes on the Pro test list).
- **Device and browser:** what they will test on, so feedback and the real-phone checklist can be matched to it.
- **Feedback channel:** an existing way you already use with this person (awaiting your selection). Testers send the feedback form there.
- **Secure credential-delivery channel:** a different way from the feedback channel, used only for the temporary password (for example a text message or a phone call).

When a tester leaves, delete their row (`owner-checklist.md`, section 5).
