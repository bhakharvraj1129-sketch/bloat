# Bloat Buddy test version: feedback form

Copy this, fill it in, and send it to the person who invited you (in the way you agreed with them). One problem per form. Made-up entries only: if you add a screenshot, check it shows nothing real.

```
Screen:          (for example: Today, Add meal, History, a day, Patterns, Doctor report, You)
Steps:           1.
                 2.
                 3.
Expected result: (what you thought would happen)
Actual result:   (what happened instead; copy any message exactly)
Device/browser:  (for example: iPhone 13, iOS 18, Safari; or Pixel 7, Android 15, Chrome)
Date and time:   (roughly, with your time zone)
Screenshot:      yes / no
```

Something that isn't a problem but could be better? Use the same form and write "Suggestion" next to Screen.
