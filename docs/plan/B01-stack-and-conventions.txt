 API conventions
  • Private endpoints authenticate and check active account. Other users' IDs return 404. 401
    unauthenticated; 403 PLAN_REQUIRED, NOT_ELIGIBLE or CAPABILITY_OFF; 409
    REVISION_CONFLICT or IDEMPOTENCY_KEY_REUSED; 422 validation; 429 throttled.
  • Every mutation sends Idempotency-Key (scoped to owner + route); edits send If-Match revision.
    Same key + same payload replays the original result.
  • Errors: {error:{code,message,details},request_id}. Times: ISO-8601 instant + IANA zone + offset
    + precision. Server derives analysis dates.
  • Pagination stable; interactive history up to 92 days; export unlimited.
  • Plan, country, consent and eligibility checks run on the server, never only in the UI.
