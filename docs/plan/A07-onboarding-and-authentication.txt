 Rules
  • Health answers are collected only after sign-up, so a Google redirect never loses health data
    (resolves the v4.1 redirect problem).
  • Onboarding answers commit atomically with original answer times and consent versions; if the
    commit reply is lost, onboarding_pending allows a same-key retry.
  • No health answers in URLs, local or session storage, analytics, replay tools or auth metadata.
  • Skipped answers are unknown. Multi-selects treat None and Not sure as exclusive (422 if
    combined).
  • Optional profile cards PF-01 to PF-06 appear one per day in the first week; all skippable.
  • Installation as a home-screen app is offered after first value; never required.

 "How Bloat works" cards
  1. Tap I feel bloated when it starts, and Bloating gone when it ends.
  2. Add meals as you eat. Pro can snap a photo.
  3. Each morning, answer a few questions about yesterday to set your Bloat Score. "Mostly" is a fine
    answer.
  4. Bloat shows patterns in your own records. It doesn't diagnose or treat anything. For worrying
    symptoms, see When to get medical help.
