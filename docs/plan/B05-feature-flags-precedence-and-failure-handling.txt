 B05. Feature flags, precedence and failure
 handling
 Precedence (server-enforced): help_page → account_rights_workflows → country_feature_readiness
 → consent → experiment_eligibility → data_quality → plan_entitlement → display_preference. A plan
 never overrides country, consent or eligibility; nothing blocks export or deletion.

 Concurrent edit                        409; reload and reconcile
