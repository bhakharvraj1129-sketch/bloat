 A14. Insights engine (Pro)
 All insights are deterministic, versioned rules over the user's own records. Every result stores metric
 version and source revision. AI never writes results.

 Possible triggers rules
  • Eligible day: confirmed (timely) score, ALL food coverage, definitive exposure, no conflict.
  • Eligible food uses the previous-evening window and excludes meals eaten after the day's
    strongest episode started (A10). Exact meal and episode times are kept; daily comparisons stay
    labelled as descriptive. Results note recalled and "mostly" days when included.
  • Never sorted by size of difference. Three sections, alphabetical inside each: Worth watching
    (difference 1 point or more and the same direction in both halves of the date range), No clear
    difference, Not enough data yet (with days still needed). Each result shows both halves: "First
    half +1.6 · second half +1.2". Header: "N groups examined; differences can appear by chance."
    [FIX 4.3.1]
  • Daily-food message: after 21 days, a group present on 80% or more of usable days shows "You
    eat {group} almost every day, so your records can't compare it. A short swap experiment can."
    The link appears only when a swap exists and the user passed FX-01 to FX-04.
  • Habits: only followed habits are compared (A13).
  • Wording: "linked to your worse days" / "no clear difference in your records". Never cause, trigger
    confirmed, safe or protective.
  • Two items appearing together: show the both / first only / second only / neither counts; if a
    discordant cell has fewer than 7 days, say the records can't separate them.
  • Context periods (illness, travel, medicine change, cycle, experiments) are shaded; an optional
    view excludes them and shows both versions.
  • Each item offers "Try an experiment" when a matching experiment exists.
