 A06. Screen-by-screen specification
 Each screen lists its purpose, layout from top to bottom, inputs (question IDs in Part C), what is
 saved, and the rules it must follow.

 01 · Landing page
 Plan                  Everyone (public)

 Opens from            Web link, ads, creator posts

 Purpose               Explain Bloat in 10 seconds and start sign-up.

 Layout                • Top bar: logo, Sign in
                       • Headline: "Track your bloating. Spot your possible triggers. Bring real data to your doctor."
                       • Three steps: tap when it starts and ends; add meals; see your patterns
                       • Free vs Pro table with the visitor's currency
                       • "How Bloat works" methodology link (how scores and comparisons are calculated)
                       • Privacy promise: no ads, no selling, delete anytime
                       • Get started button
                       • Footer: intended-use statement, When to get medical help, Terms, Privacy, Contact

 Inputs                None

 Saves                 • Nothing (cookieless page analytics only, no health data)

 Rules                 • Wording follows the allowed marketing list
                       • Price shown by visitor country; USD default

 04 · When to get medical help
 Plan                Everyone

 15 · Today
 Plan                Everyone (Pro cards for Pro)

 Opens from          Tab

 Purpose             Home: log fast and see today.

 Layout              • Date and Today
                     • Review yesterday card (until done)
                     • Today card: Highest logged so far, episodes, time bloated
                     • I feel bloated button, or the Bloating ongoing card
                     • Add meal · Add activity · Log bowel movement (Pro)
                     • Pro: experiment card (Day N of 7, Yes / Partly / No)
                     • Pro: today's card (one a day, alternating tip and mind–body)
                     • Pro: next best log suggestion
                     • Free: progress counter (days logged · confirmed days still needed for possible triggers)
                     • Pro: phase label (Discover / Understand / Maintain)
                     • Never a doctor card or pop-up (the doctor line lives in History and reports)
                     • Keep an eye on it mode: watched groups shown instead of meal prompts
                     • Timeline of today's entries
                     • Bottom tabs: Today · History · Me

 Inputs              Navigation; XP-02 on the experiment card

 Saves               • None directly

 Rules               • Never shows a confirmed Bloat Score for today
                     • No duplicate open episode
                     • Progress counter uses real counts only

 30 · Possible triggers
 Plan                Pro

 Opens from          26

 Purpose             Foods and habits linked to worse days.

 Layout              • Header: groups examined (N), date range, recalled and mostly day counts
                     • Worth watching (alphabetical): with/without averages, day counts, both halves
                     • No clear difference (alphabetical)
                     • Not enough data yet: "X more days needed"
                     • Eaten almost every day: daily-food message with swap link if eligible
                     • Note: only followed habits are compared
                     • Co-occurrence note when two items usually appear together
                     • Try an experiment button where one exists

 Inputs              Range

 Saves               • comparisons

 Rules               • Fixed wording; never causes, never safe/bad
                     • Never sorted by size of difference
                     • Previous-evening window (from 18:00) for food
