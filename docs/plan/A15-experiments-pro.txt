 Swap experiments (after FX check) [FIX 4.3.1]
 The user swaps one food group for a named equivalent, so nothing is missing from their diet. This
 replaces cut-back food experiments, lactose trial and gentle FODMAP, which normally need
 professional supervision.

  • Never offered: wheat or grains (TAG-02), several groups at once (FODMAP programmes), any
    group without a like-for-like swap. Fizzy drinks are covered by the habit experiment.
  • At most 2 swap experiments in any 180 days; one experiment of any kind at a time.
  • FX-01 to FX-04 asked before each swap; anything other than No means swaps are not offered
    (habit experiments still are).
  • WB-01 and WB-02 weekly; a Yes pauses the swap and shows the country helpline.
  • Every swap screen shows "Stop if you feel worse" and a link to When to get medical help.

 State machine
 PROPOSED → (eligible, prior 4+ confirmed days) → RUNNING → [swap: ADDING_BACK] →
 COMPLETED. RUNNING → PAUSED (WB Yes) → RUNNING or ENDED_EARLY. Any → ENDED_EARLY
 (XP-03). One experiment per user at a time.

 Enough data = 4+ confirmed days in each period and 4+ "Yes" days.
