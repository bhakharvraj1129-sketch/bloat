# Bloat

An installable mobile-web bloating tracker: record bloating, meals and habits, see patterns in your own records, try simple experiments, and take a clear report to your doctor. A general wellness tracker, not a medical product.

Status: planning pack and project rules only. No application code yet. See `PROGRESS.md`.

## Folder map

- `CLAUDE.md`: standing rules Claude reads at the start of every session
- `PROGRESS.md`: what is done and what is next
- `DECISIONS.md`: choices made, and questions waiting for the owner
- `docs/plan/`: Bloat Complete Plan v4.5, one text file per section
- `docs/data/`: questions, acceptance tests and configuration (JSON)
- `docs/design/`: design tokens, brand rules, approved screens
- `docs/slices/`: one brief per build slice
- `docs/source-pdfs/`: the original plan and build guide PDFs
- `docs/skills-sources.md`: where the outside skills came from
- `.claude/skills/`: the skills Claude loads for this project
